# Procedure: how this tool grades a PR package

## Read order
Select mode. Live reads scope first and stops on placeholders or outside targets, then reads voice. Eval ignores both. Read rubric and evidence guide; refuse empty rubric or procedure. Read issue, repro and thread, then plan before diff. Read complete diff, commits, tests and repository requirements. Read title and description against those facts.

## Evidence gathering
Pair changed behavior with plan commitments or deviations, description claims with diff/output, regression commands with baseline/expected after, and required checks with outcomes or blocks. Inspect hunks for debris. Pair template obligations and maintainer requests with draft responses. Record live voice notes separately.

## Check execution
Execute every check in rubric order. Cite a concrete deciding fact or quote. Pass demonstrated satisfaction; fail demonstrated omissions or contradictions; mark unavailable required evidence unclear. Re-read relevant conflicting evidence. Apply limitation rules. Report procedure gaps without inventing substitute checks.

## Verdict assembly
Apply the rubric. Identify the first non-passing required check as the primary hold reason while retaining all grades. Report live voice notes before JSON. Emit the exact contract schema in rubric order, valid and last, with nothing following. Never call an interrupted or manual review a completed live verdict.
